# Noteline

> A calm, local-first note editor for people who just want to write.

---

## Philosophy

Noteline exists for one simple reason:

> I wanted a note editor that I would actually use.

No cloud.
No accounts.
No sidebars full of features I never asked for.
No Electron.
No “second brain”.
No AI assistant.

Just text.
Saved locally.
Quietly.

---

## Why Noteline Exists

On weaker machines, even browsers lag.
Modern software is heavy, abstracted, and overdesigned.

Noteline was built with a different mindset:

* Respect hardware.
* Respect attention.
* Respect ownership.

Your files stay on your system.
The application does one job — and gets out of the way.

---

## Features

* 📂 Open any text file
* 💾 Auto-save every 3 seconds
* 🔤 Adjustable font size (+ / − / direct selection)
* 🎨 Text color selection
* 🌗 Dark / Light mode toggle
* 🖥 Desktop-native layout (compact, sharp, mouse + keyboard friendly)
* 🚫 No background services
* 🚫 No telemetry
* 🚫 No cloud

---

## Design Principles

### 1. Local First

Files are the source of truth.
No hidden formats. No proprietary storage.

### 2. Calm UI

Small window.
Dense layout.
No oversized mobile-style components.

Built for 16–32 inch monitors — not touch screens.

### 3. Safety Without Noise

Auto-save runs quietly in the background.
No popups.
No anxiety.

### 4. Minimal Surface Area

If a feature doesn’t improve writing, it doesn’t exist.

---

## Auto-Save

Noteline automatically saves the current file every 3 seconds.

This keeps workflow uninterrupted while protecting your work.

No manual “Save” ritual required.

---

## System Requirements

* Linux (AppImage build provided)
* Python + CustomTkinter (for source version)

Designed to run comfortably even on modest hardware.

---

## Why It’s Not Open Source (For Now)

Noteline is free to use.

It is not open source at this time.

The goal is to build a collection of small, useful native tools that prioritize reliability and simplicity over ecosystem noise.

---

## What Noteline Is Not

* Not a Markdown editor
* Not a knowledge base
* Not a productivity system
* Not a collaboration tool
* Not a startup product

It is a personal utility — shared.

---

## Roadmap (Maybe)

Improvements will only be added if:

* They solve real friction
* They keep the software calm
* They don’t increase complexity

If it works well as-is, it may remain exactly as it is.

---

## Closing

Noteline is a small tool.

But small tools, used daily, matter more than big ideas never finished.

If you use it and it helps you think more clearly —
then it has already succeeded.
